# Security and privacy

Do not post bot tokens, Home Assistant backups, RouterOS exports, private logs,
family records or configuration storage in public issues.

Report a vulnerability privately using GitHub's security advisory flow for this
repository when available. Until private reporting is enabled, open a minimal
issue asking for a private contact without disclosing exploit details or data.

Roles are checked server-side. A hidden dashboard button is not authorization.
No language model can grant itself privileges or execute shell commands.

The development branch is not ready for production migration. See the
implementation matrix for completed tests and remaining security gates.
