# Family Assistant 0.1.0-alpha.10

Development prerelease for isolated evaluation, not a completed household cutover.

- Legacy text-report proposals now follow explicit assignment changes. A previous
  person's report, review, submission time and identity remain in parent-only
  history; they never become the new assignee's current report. Reassigning back
  does not restore a prior confirmation. Tampered chains, obsolete identities
  and progress attributed to a former assignee remain explicit blockers.
- No-report tasks and self-only reminders can preserve distinct completion,
  cancellation and archive notes, reconstructed from complete source events.
  A note does not become a report, approval or new permission. Personal reminders
  remain invisible to other household members, including parents.
- Isolated actual-HA acceptance covers exact source-byte archive/reload and
  reproducible proposals for both reassignment and private terminal notes.

Photo evidence resolution, historical reviewer compatibility, coherent source
capture, fully isolated shadow import and controlled live cutover remain open.
This release introduces no import/apply endpoint and does not touch production.

See the [migration contract](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.10/docs/legacy-migration.md)
and [acceptance matrix](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.10/docs/implementation-status.md).
