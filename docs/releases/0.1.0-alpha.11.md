# Family Assistant 0.1.0-alpha.11

Development prerelease for isolated evaluation. Full migration/cutover is not yet complete.

- A task that requires a future photograph can now produce a read-only migration
  proposal when its full source history contains no submitted photo. The new
  task still requires verified media; an old caption or reference is not turned
  into an attachment. Explicit historical parent completion is retained as an
  outcome, not fabricated photographic proof or new authority.
- Late acceptance/start can be recovered from a complete reconciled source
  history even when old pre-overdue metadata lagged behind or was never recorded.
  The exact activity timestamps and deadline remain intact. Missing events,
  reassignment mismatches and a later source revision that actually rewound
  progress remain visible blockers, not guesses.
- Actual-HA Store acceptance includes an overdue, started, not-yet-submitted
  photo task alongside the prior report-reassignment and private-note cases.

Existing submitted photo evidence still requires explicit resolution. Coherent
capture, complete shadow import, historical reviewer compatibility and controlled
production cutover remain separate gates. There is no import/apply endpoint.

See the [migration contract](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.11/docs/legacy-migration.md).
