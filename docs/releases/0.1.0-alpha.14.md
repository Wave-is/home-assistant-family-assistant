# 0.1.0-alpha.14 — optional reminders on return home

Evaluation prerelease, not stable production or a completed legacy migration.

- Separate off-default self/guardian consent for selected private nonurgent
  reminders. No implied access from dashboard sharing or another adult's consent.
- Current HA account, read permission, registry, source binding and fresh report
  checks before delivery; unknown is not home. No observations retained.
- Durable bounded holds, expiry, pinned recipient, return catch-up rate, ordinary
  urgent/reply/group lanes and explicit withdrawal. No stale revival after downtime.
- RU/UK/EN card with explicit review, wait limit, exact response-loss retries and
  invalidation after identity, member, binding, module or entry changes.
- Actual HA authenticated Options/consent/ACL/Store/outbox tests use an isolated
  synthetic household and no external transport.

See [the three-language guide](../presence-notifications.md). User settings remain
private and off by default; no home configuration or device operation is part of
this release. Default HACS catalog inclusion, live Telegram/hardware acceptance,
legacy migration/cutover and the remaining vision are separate gates.
