# 0.1.0-alpha.15 — reviewed local network device inventory

Evaluation prerelease, not stable production or a completed migration.

- Separate owner-reviewed approval ledger: protected/approved/unreviewed rows.
  HA names and DHCP comments never silently authorize a device.
- Fresh complete inventory, actor/source/policy-bound two-minute plans, explicit
  before/after confirmation, write-free replay and source-change archiving.
- RU/UK/EN Home network card with mobile review, read-only parent view and exact
  response-loss retry; stale/detached confirmations cannot submit.
- Deterministic private Telegram unknown-device commands, group-to-private
  redirect and send-time revocation after source/identity/freshness changes.
- Authenticated actual-HA ledger/Store/replay and isolated browser checks.

This feature changes local records only. It does not alter DHCP reservations,
Wi-Fi, firewall or Kid Control. Automatic alerts, quarantine and strict network
enforcement remain separate work, not hidden active modes.

See [the three-language guide and capacity limits](../network-admission.md).
No household settings, tokens, MAC addresses or production actions are included.
