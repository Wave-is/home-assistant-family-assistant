# 0.1.0-alpha.18 — private equipment documents

Evaluation prerelease, not completion of the full vision or a production migration.

- Maintenance card: separate private upload and explicit attachment of manuals,
  warranties, receipts and other equipment documents; RU/UK/EN controls and guide.
- Current parents/owner only. Pending files remain uploader-only; children, guests,
  Telegram and AI receive no document access. Equipment/service revisions remain intact.
- Static JPEG/PNG/WebP and restricted PDF with pinned `pypdf==6.17.0`. Strict PDF
  parsing rejects encryption, embedded files, forms and actions under bounded helper
  resources. This is not antivirus protection; original metadata may remain.
- Explicit authenticated downloads only, no inline PDF/image rendering. Owner-only
  reviewed removal revokes reads immediately; collection and retained history are
  distinct. Existing backups are not erased. Removed history has bounded card pagination.
- Frozen operation receipts survive lost responses; identity/equipment/module changes
  revoke stale drafts and in-browser private links. Photo-report purposes still reject PDF.
- Offline HA acceptance installs the hash-pinned public wheel only in disposable
  network-none/capability-free containers. No production packages or containers change.

Guide: [English / Русский / Українська](../equipment-documents.md).
Private files and Store state remain outside the HACS-managed directory. Take the
normal verified HA backup before upgrading; restore metadata and bytes coherently.
No household documents, credentials, or configuration are included in this release.
