# 0.1.0-alpha.19 — explicit migration reviewer comparison

Evaluation prerelease; no live import, household cutover or role changes.

- Joined legacy conversion review can include a complete, explicitly supplied
  per-task source reviewer policy. A designated reviewer alone is not assumed to
  represent every parent authorized by the old controller.
- The immutable comparison pins source/mapping, policy revision and all current
  target identities. Added/removed reviewers are private per-task differences;
  public summaries expose only counts, fixed status and fingerprints.
- Missing, duplicate, unresolvable or incomplete policy fails closed. Missing
  comparison is explicitly `not_supplied`; role grants and import permission are
  never inferred, even for equivalent sets.
- This comparison does not prove the truth of a supplied source policy or coherent
  capture. Source export, evidence conversion, isolated shadow import and controlled
  cutover remain separate unfinished gates.

The public runtime does not depend on a developer PC or a private source adapter.
No household sources, names, bindings or credentials are included in this release.
Guide: [legacy migration contract](../legacy-migration.md).
