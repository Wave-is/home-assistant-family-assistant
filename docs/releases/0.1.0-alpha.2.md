# Family Assistant 0.1.0-alpha.2

Development prerelease for an **isolated Home Assistant instance**. This is not
a production migration release or completion of the [product vision](../vision.md).
Do not replace a working family system with this prerelease.

## Included

- One HACS integration with separate family shopping, tasks, alarms, points,
  calendar, routines, meals, school and optional network modules.
- Owner-managed family members and roles, configurable household time zone,
  English/Russian/Ukrainian interfaces and seventeen dashboard views.
- Your own Telegram bot, owner-confirmed group/member linking, deterministic
  commands, an optional configured language model and fallback, and reviewed
  model-generated changes.
- Complete reviewed recurring-task and alarm editors, revision checks, exact
  retries and private photo-task reports.
- Explicit public-article reading in the Conversation card, off by default,
  with separate child access, bounded public HTTPS retrieval and source links.
  Article synthesis does not receive family context.
- Ordinary Conversation chat with bounded requests, member/provider/runtime
  authority checks and exact Retry after response loss. Telegram, Assist, LLM
  tools and HA commands also reject stale queued authority; successfully
  unloaded runtimes cannot continue writing family data.
- Runtime-only deterministic packaging, privacy checks, actual Home Assistant
  acceptance and a two-process application-upgrade gate using synthetic data.

See the [implementation matrix](../implementation-status.md) for precise
implemented, tested and still-pending boundaries. A feature being listed here
does not certify its production provider or physical-device behavior.

## Evaluate safely

Follow the [English](../setup.en.md), [Russian](../setup.ru.md) or
[Ukrainian](../setup.uk.md) setup guide. Add this repository as a **HACS custom
repository**, category **Integration**, and enable prerelease versions if needed.
HACS default-catalog inclusion has not been granted by publishing this release.

Family data and credentials remain in Home Assistant-managed configuration and
Store data, outside the HACS code directory. The optional downloadable ZIP
contains only `custom_components/family_assistant/`; it contains no household
configuration, bot token, router access or private data.

With the current `hacs.json`, HACS installs the integration subtree from the
selected GitHub tag archive. The optional runtime ZIP is a separate deterministic
artifact for byte verification/manual extraction, not a HACS `zip_release`
asset. Installer acceptance must compare the installed runtime bytes, not assume
the two transport archives are identical.

## Not yet certified

Existing-home migration, full Home Assistant backup restoration, real Telegram
and model acceptance, physical alarm audibility, and every router topology need
their separate checks. Some vision extensions remain in development. Article
reading is not yet a Telegram command. Do not enable network writes or bind a
physical siren merely to evaluate the user interface.
