# 0.1.0-alpha.20 — persistent read-only migration copies

Evaluation prerelease; no live importer, migration wizard or household cutover.

- Whole-candidate construction rejects blocked records, reviewer changes and a
  nonempty target. Explicit IDs, partial purchases, current-week totals and the
  complete private source archive survive deterministic replay.
- A distinct persistent shadow schema prevents earlier releases from loading the
  copy as an ordinary writable household. Clock/commands/internal writes and
  Options changes remain denied after reload or backup release.
- A shadow runtime starts no transport, provider, scheduler or device workers,
  including when stale Options incorrectly enable them. Current-owner-only views
  and RU/UK/EN cards expose read-only summaries without mutation controls.
- No real household data, credentials, bot or device effects are included.

Coherent source capture, historical photo resolution, reviewer decisions and a
controlled activation/cutover remain unfinished. Do not manually edit Store files
or the isolation marker. [Three-language guide](../legacy-shadow.md).
