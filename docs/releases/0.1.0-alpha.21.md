# 0.1.0-alpha.21 — owner-matched historical photo evidence

Evaluation prerelease, not a live migration installer or household cutover.

- Explicit complete event-to-image matching, actual bounded image decoding and
  exact source/member fingerprints; legacy strings never become fake files.
- Whole shadow copies retain current and previous photographs with their original
  assignee revisions. An exact private blob set accompanies the Store data.
- Private archive replay redecodes each image and refuses substituted metadata or
  files. Only the current owner can read attachments in a loaded shadow.
- Normal task-photo permissions, shadow write isolation, zero provider/device
  workers and raw source preservation remain unchanged.

There is no public matching/import/activation endpoint, automatic Telegram file
retrieval or live source cutover. [Three-language guide](../legacy-photo-evidence.md).
