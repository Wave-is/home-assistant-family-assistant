# 0.1.0-alpha.22 — reviewed local shopping barcodes

Evaluation prerelease; not a production migration or full-vision completion.

- Optional GTIN metadata with strict check-digit validation and equivalent
  14-digit normalization. Existing uncoded shopping records continue unchanged.
- RU/UK/EN manual entry, reviewed add/edit and opt-in local camera scanning in
  supported secure browsers. Manual/keyboard-scanner fallback remains available.
- Camera cleanup on success, cancellation, identity change, hidden/unmounted page
  and a one-minute deadline; late permission/detection cannot fill another draft.
- Recurring templates retain codes; history preserves the code at purchase time.
  Different or missing codes cannot silently merge. Quantities and child approval
  are unchanged, and uncertain saves retain their exact idempotent retry.

No third-party barcode dependency, external product lookup, image upload or
automatic purchase. A scan fills the code, not a guessed product name. Physical
camera/native-decoder support is browser-dependent; the browser acceptance suite
uses synthetic local video. [Three-language guide](../shopping-barcodes.md).
