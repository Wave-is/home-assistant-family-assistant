# 0.1.0-alpha.25 — private read-only copy wizard

Evaluation prerelease. The new wizard creates an isolated read-only copy, not a
production cutover or activation of old automations.

- The original household owner, also a current HA administrator, can open the
  legacy-copy Options flow and upload a private bounded ZIP using native HA
  FileSelector/file_upload. The prototype is not overwritten or reconfigured.
- Exact participant, reviewer and historical photo associations are reviewed in
  nonce-bound pages. Counts and the whole-copy fingerprint require a separate
  final confirmation before any integration Store or ConfigEntry is written.
- A private immutable retry intent pins the same package/target to its original
  entry ID and preparation time. Reuploading the exact same bundle with unchanged
  target members/name recognizes the same sealed copy, without another entry.
- Current owner/runtime/member pins propagate through staging and registration
  writes. One bounded, time-limited review slot and settled executor cancellation
  prevent accumulation of parallel private ZIP parsing jobs.
- Explicit discard releases only the current review; existing copies and saved
  retry coordinates are preserved, including after uncertain results.
- ZIP validation bounds central-directory allocation and member sizes, rejects
  duplicate/traversal/extra/symlink/encrypted/unsupported entries and inconsistent
  local-header flags. Nothing is extracted into a directory. Historical image
  evidence uses the existing independent bounded decoder.
- English, Russian and Ukrainian steps/errors and the preparation/limits guide
  are included. Native HA tested actual authenticated upload, stale-page rejection,
  confirmation, three historical photos, separate read-only registration, reupload
  replay, unchanged prototype and test cleanup.

Bundle preparation and coherent source capture remain operator-assisted. Images
must be inspected locally; displaying associations is not proof of photo content.
No source installation, household bot, siren or router was changed. No automatic
activation, old-integration replacement or residue deletion is introduced.
