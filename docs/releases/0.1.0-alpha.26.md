# 0.1.0-alpha.26 — cross-ledger migration checks

Evaluation prerelease, not a production cutover.

- A whole-copy guard reconciles explicit automatic Court penalties against task
  rollover history and alarm acknowledgements. Historical assignees are retained
  after reassignment. Duplicate, malformed, one-sided or mismatched effects and
  unfinished score corrections block creation rather than silently changing data.
- The Options wizard gives a specific English/Russian/Ukrainian source-consistency
  error before Store/ConfigEntry publication. Manual Court decisions stay distinct;
  missing pruned alarm history outside the current Court period is archive-only,
  not represented as verified.
- An internal deterministic private ZIP packager validates bounds before
  allocation and rechecks output with the independent parser. Exact source bytes
  and photo associations stay private; packaging does not grant rights or prove
  image content/capture coherence.
- Synthetic tests cover receipt gaps, duplicates, assignment history, correction
  request/reversal/acknowledgement, archive-only alarms, strict timestamps and ZIP
  determinism. An isolated actual legacy-controller test reproduced Court-first
  commit, safe idempotent settlement and completed correction without device calls.
- Independent review added regressions for pruned alarm keys charging a different
  or unknown participant, malformed reporting periods and invalid correction
  acknowledgements. Archive-only does not excuse contradictory identity data.

No legacy source, household bot, siren or router was changed. Coherent final source
capture, a user-facing source exporter/mapping editor, activation and controlled
cutover remain separate gates. Existing source history is never deleted to make a
failed check pass.
