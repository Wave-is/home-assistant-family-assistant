# 0.1.0-alpha.27 — native private-copy preparation

Evaluation prerelease; not live migration or activation.

- Prepare a private read-only copy through native HA forms: two exact source
  files, explicit participant choices, complete old reviewer sets and each original
  historical photo. No hand-written mapping JSON or manually assembled ZIP needed.
- English, Russian and Ukrainian instructions explain source-coherence limits,
  additional reviewer identities, archive-only mapping, file bounds and safe retry.
- Preparation shares the existing owner/admin-bound single private memory slot.
  Stale pages, duplicate target identities, changed rights, member revisions,
  expired reviews and contradictory source data are rejected. Cancellation drains
  an in-progress reader before releasing its slot; private errors reveal no data.
- Deterministic packaging feeds the existing paged association/final fingerprint
  review and separate sealed entry. Repeated exact files and choices retain the
  same retry identity. Discard never deletes an existing copy or retry intent.
- Actual isolated HA verified two member selections, two complete reviewer sets,
  three source images, exact repeat, and discard preserving the copy, retry intent
  and original household. Host verification passed 3,990 Python tests and 450
  frontend tests (plus 141 pretests); five host-dependent Python tests were skipped.

No household bot, router, siren or source data was changed. A supported coherent
source exporter, reviewed residue recovery and controlled activation/cutover remain
separate requirements. Owner-supplied reviewer sets are not automatically proven.
