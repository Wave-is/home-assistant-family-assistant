# 0.1.0-alpha.29 — private proposal correction notes

Evaluation prerelease; not full-vision completion or a household cutover.

- Reject an unexpired model proposal with a category and expected intent. Optional
  original text is accepted only after exact local hash verification. No command,
  learned phrase or automatic fix is executed by saving a note.
- Rejection and note commit atomically. Exact retries, Store failures, member
  revision fences, scoped purge and corrupted/capacity-bounded storage are tested.
- Notes are actor-private, not anonymous; parents cannot read child notes through
  this interface. No note contents enter LLM context or technical reports.
- EN/RU/UK cards preserve failed-write drafts and discard revoked-account drafts.
  Private Telegram `/feedback` avoids a second raw-text interpretation-plan copy;
  group submissions are refused. Ordinary `/cancel` still needs no note.
- At most 64 active notes, with no silent eviction. Purge removes only the selected
  note, not original messages/proposals/receipts/backups. Prior identity revisions
  remain quarantined; this is not a full retention or semantic-reproducer solution.
