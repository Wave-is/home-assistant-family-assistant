# Family Assistant 0.1.0-alpha.3

Development prerelease for isolated Home Assistant evaluation only. It is not a
production migration release or completion of the product vision.

- Media health now reports blocked capacity when the next upload reservation
  cannot fit in the byte budget or the household pending ceiling is reached.
  Per-member limits do not incorrectly block other members. No quotas or
  deletion behavior changed.
- Strict, private legacy Store decoding and immutable source/member-mapping
  review, with duplicate-key/JSON bounds and unchanged-input verification.
  Historical system actors do not gain target rights. This is not an importer;
  coherent capture, conversion and controlled household cutover remain pending.
- Setup guides now distinguish published test prereleases from a stable release.

See the [implementation matrix](https://github.com/Wave-is/home-assistant-family-assistant/blob/main/docs/implementation-status.md)
and [legacy migration boundary](https://github.com/Wave-is/home-assistant-family-assistant/blob/main/docs/legacy-migration.md).
Use your own bot/providers on an isolated test instance. Do not replace an
existing family installation or enable physical sirens/network writes just to
evaluate the cards. HACS default-catalog inclusion is a separate review.
