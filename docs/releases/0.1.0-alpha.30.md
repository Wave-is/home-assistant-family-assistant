# 0.1.0-alpha.30 — preserve interrupted copy uploads

Evaluation prerelease; not full-vision completion or a household cutover.

- Interrupted, unregistered read-only copies can offer a separate EN/RU/UK
  preservation review. Exact candidate, owner, target and temporary files are
  pinned; prior copy consent never implies cleanup permission.
- Recognized partial uploads and photo-publication hardlinks are bounded and
  checked. Foreign files, external links, drift and registered entries fail closed.
  Completed photos and the family Store are never reset.
- Native Store journals allow exact retry after failed acknowledgement. All
  selected bytes are archived and verified before removing temporary source names.
  Registration retries the same sealed copy.
- Recovery archives stay private and retained. No automatic deletion, activation,
  source capture, global pending-copy discovery or resume without the original
  bundle. Larger/foreign residues require separate review.
