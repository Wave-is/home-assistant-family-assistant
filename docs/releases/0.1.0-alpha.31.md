# 0.1.0-alpha.31 — discover and resume saved read-only copies

Evaluation prerelease; not full-vision completion or a household cutover.

- Owner-private EN/RU/UK Options discovery uses a bounded native Store index,
  recorded only after final copy confirmation and before staging begins.
- Complete staged Stores and photos are reverified through actual converters;
  summary metadata or a seal alone cannot authorize resume.
- A fresh confirmation retries registration of the same sealed copy and ID,
  without uploading the ZIP again. Partial, changed or foreign state fails closed.
- Identity/runtime/member guards apply during asynchronous reads and confirmation.
  Cancel closes only the review; originals, index and completed copies remain.
- Sixteen retained immutable attempts per instance; no automatic eviction or
  discovery of older unindexed attempts. No startup repair, activation, coherent
  source capture or general cleanup interface is supplied.
