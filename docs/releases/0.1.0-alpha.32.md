# 0.1.0-alpha.32 — reviewed task batches

Evaluation prerelease; not full-vision completion or a household cutover.

- Parent-only EN/RU/UK Tasks-card selection and separate review of up to 20
  ordinary shared tasks for completion, cancellation or terminal-task archive.
- One atomic native batch, pinned task revisions and an explicit same-ID retry
  after uncertain responses; no partial completion or automatic revision rebasing.
- Personal reminders and specialized-module tasks retain their individual flows.
- Fresh-process sealed-copy resume is now an additional CI acceptance gate.
