# 0.1.0-alpha.33 — independent multi-person assignments

Evaluation prerelease; not full-vision completion or household cutover.

- Parents can prepare the same one-off chore for multiple selected members,
  with explicit review: each receives a separate task, checklist and report.
- Creation is one atomic transaction; no partial group on stale identities,
  invalid members or failed persistence. Optional reviewed member revisions are
  checked under the command lock without breaking legacy callers.
- The creation form retains its own frozen operation ID on uncertain retry,
  independent of unrelated card commands. Personal reminders remain self-only.
- A late response from an older card session cannot unlock a newer write.
  Review time matches the actual entered deadline, including DST occurrences;
  reopening an unsent review requires fresh confirmation.

No production household, bot, router or legacy installation was changed.
