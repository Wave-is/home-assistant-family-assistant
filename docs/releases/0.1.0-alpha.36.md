# 0.1.0-alpha.36 — strict preconditions gate, watch incident lifecycle and trilingual parity

Evaluation prerelease, not full-vision completion or household cutover.

- **MikroTik strict enforcement precondition gate**:
  - Hard precondition matrix evaluating router readiness before strict admission enforcement: module active, topology evidence recorded within 30 days, backend identity match, IPv4 restriction rules verified, IPv6 restriction rules verified, FastTrack bypass accounted for, management hosts excluded, restart recovery verified.
  - Owner-only evidence recording via `mikrotik.network_record_strict_evidence` with backend binding and capacity limit.
  - Card view projection exposes `strict_available` and `unmet_preconditions` with 9 explicit reason codes.
  - Engine replay authorization ensures recorded evidence matches current topology evaluation.
  - 17 unit tests verifying all failure modes, expiration, replacement, and replay.

- **Network watch incident lifecycle closure**:
  - Explicit incident tracking in `network/watch.py` tick(): opens upon detecting new unreviewed devices, persists while any tracked devices remain unreviewed, and properly closes when all tracked devices are reviewed.
  - Sends localized closure notification `network_watch_cleared` across EN, RU, and UK once devices are reviewed.
  - Unannounced incidents (e.g. during quiet hours) close silently without notification if resolved before quiet hours expire, honoring unannounced incident safety.
  - 44 tests in `test_network_watch.py` covering discovery, pacing, quiet hours, and lifecycle transitions.

- **Trilingual localization parity (RU / UK / EN)**:
  - Complete 975-key parity across `strings.json`, `translations/en.json`, `translations/ru.json`, and `translations/uk.json`.
  - Added localized `strict_precondition_reason` selector options in all three languages.
  - 100% key parity across all Telegram message templates in `telegram/messages.py`.
  - Verified by `test_public_contract.py` and `tools/sync_locales.py --check`.
