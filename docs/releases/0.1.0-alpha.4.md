# Family Assistant 0.1.0-alpha.4

Development prerelease for isolated evaluation, not a household migration or
completion of the product vision.

- Exact model response schemas and a discriminator-first wire format prevent
  several malformed-response and missing-command failures observed on real Qwen.
  Stored command proposals keep their existing canonical format.
- Weekday/weekend alarm expressions are grounded in the current request and
  converted deterministically. Numeric model guesses cannot create or change days.
  Clock-only edits can preserve a known schedule. Errors are localized in EN/RU/UK.
- Raw quoted text no longer enters the action planner. Ordinary discussion of a
  quote uses a separate answer-only pass without family records or write tools.
- Shopping context includes the actual already-purchased amount.
- An explicit opt-in synthetic-only model evaluator keeps intent failures,
  timeouts and privacy boundaries visible. It never executes against Home Assistant.
- Upgrade CI now starts from the exact published alpha.3 release.

See the [model evaluation boundary](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.4/docs/model-evaluation.md)
and [implementation matrix](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.4/docs/implementation-status.md).
Use your own bot/providers on an isolated test instance. Stable acceptance,
legacy conversion/shadow cutover and HACS default-catalog inclusion remain separate.
