# Family Assistant 0.1.0-alpha.5

Development prerelease for isolated evaluation only; not a household migration.

- Private legacy alarm conversion proposals now revalidate frozen sources and
  every current target-member field. Revoked identities, stale mappings and
  manually forged review metadata fail closed.
- Weekday/weekend schedules can be represented as modern disabled, gentle,
  zero-penalty payloads. Source schedules, finished runs and unknown fields remain
  in a lossless private decoded archive; old challenges and delivery rights are
  never made active. Summary output is counts/fingerprints only.
- This is a pure planning helper, not an importer. Coherent capture, complete
  task/shopping/court conversion, private archive persistence, shadow acceptance
  and controlled cutover remain required.

See the [migration boundary](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.5/docs/legacy-migration.md)
and [implementation matrix](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.5/docs/implementation-status.md).
