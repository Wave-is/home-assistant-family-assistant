# Family Assistant 0.1.0-alpha.6

Development prerelease for isolated evaluation only, not a household migration.

- A joined immutable conversion review inventories all legacy buckets and retains
  blocked records. Unknown shopping quantities, unsupported precision/states,
  private reminders and unverified report/reviewer semantics stay explicit.
- Separate shopping proposals preserve approval and partial purchases. Court
  proposals reconcile the source open week without reactivating cancelled or old
  penalties. Task proposals preserve supported progress/dates and refuse ambiguous
  overdue progress; imported alarm schedules remain disabled.
- An owner-private archive codec preserves the exact original source bytes across
  save/load and rechecks current member bindings. It is not a diagnostic export,
  an authorization token, or proof of coherent capture.
- The actual-HA acceptance suite now includes Store archive roundtrip and proposal
  reproducibility using fictional data only.

No live import, migration UI, shadow activation or cutover is included. These
helpers must not be used to perform a partial household migration. See the
[migration contract](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.6/docs/legacy-migration.md)
and [remaining requirements](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.6/docs/implementation-status.md).
