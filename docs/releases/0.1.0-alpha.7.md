# Family Assistant 0.1.0-alpha.7

Development prerelease for isolated evaluation, not a complete legacy migration.

- Parents can read one week from an already connected HA calendar into an unsaved
  school timetable draft. RU/UK/EN controls retain the normal explicit final review
  and save. No calendar writes, background synchronization or inferred school-year
  recurrence. HA read permission and family identity are checked before/after I/O;
  late results cannot overwrite changed drafts or survive revoked authority.
- Strict event conversion rejects all-day, overlapping, out-of-week, sub-minute
  and ambiguous DST-fold events without silently dropping rows. Source descriptions
  are not copied or sent to an LLM.
- An additional CI gate now runs native encrypted Core backup restoration and
  fresh authenticated startup, with deliberately changed synthetic data and a
  damaged attachment. This is separate from the HACS installer upgrade gate.

See [school setup](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.7/docs/school.md),
