# Family Assistant 0.1.0-alpha.8

Development prerelease for isolated evaluation, not complete household migration.

- RU/UK/EN Tasks cards now support explicit personal reminders: self-only
  visibility, self completion/archive, fixed assignee, no parent review or court
  consequences. A private due notice is persisted once and survives restarts.
- Current identity is checked for reads, mutations, exact replay and delivery.
  Other household parents/owners cannot obtain these records through task lists,
  mixed-batch audit results, delivery-review rows or the public task-count sensor.
  Personal content is excluded from group bot context and LLM planning.
  Private task list/confirmation replies carry a persisted no-quote marker, so
  replying to them does not automatically export personal text to a model.
- Legacy no-report reminder proposals preserve personal scope and mapped identity
  instead of becoming family-visible tasks. Raw source/history remain in the
  private conversion archive. Report/media conversion, coherent source capture,
  full shadow import and live cutover remain separate unfinished gates.

Application-level privacy does not encrypt data against the HA server administrator;
local configuration and backups must be protected. Missing private Telegram
enrollment does not fall back to parents or a group. This is not an emergency alarm.

See [personal reminders](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.8/docs/personal-reminders.md)
and the [remaining requirements](https://github.com/Wave-is/home-assistant-family-assistant/blob/0.1.0-alpha.8/docs/implementation-status.md).
