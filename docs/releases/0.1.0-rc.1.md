# 0.1.0-rc.1 — migration critical smoke, trilingual rollback guide and shadow mode isolation

Release candidate for Stage 2 (`v1-rc` preparation), validating a safe migration path from legacy installations to Family Assistant v1 without modifying live configuration or executing unreviewed mutations.

- **7-Module Shadow Migration Smoke Suite (`tests/test_migration_critical_smoke.py`)**:
  - Strict shadow isolation under schema `legacy-shadow-v1` with empty active module list (`modules: []`).
  - Read-only invariant enforced across all modules: any write operation or periodic `tick()` immediately raises `DomainError("migration_shadow_read_only")`.
  - **Tasks**: Retains original IDs, titles, due dates, progress states (`in_progress`, `submitted`), and private reports; write mutations blocked.
  - **Shopping**: Conversion into isolated space `S000001`, preservation of item quantities, purchased counts, units, and approved status; mutations blocked.
  - **Alarms**: Gentle schedule conversion with disabled flags, zero penalty rates, active execution clears, and ticks blocked.
  - **Court**: Open weekly snapshot migration to space `C000001`, point balance preservation, and mutations blocked.
  - **Routines & Calendar**: Clean empty structures, disabled state, and execution/tick calls blocked.
  - **Network & Kid Control**: Safe empty state, strict-mode activation prevented (`module_disabled`), profile/schedule mutations blocked.
  - **Dashboard**: Read-only shadow view projection (`migration_shadow_read_only`), owner-only administrative access, migration archive hidden from regular card views, and child/parent non-owner access denied (`forbidden`).

- **Trilingual Migration Contract & Rollback Guide**:
  - `docs/legacy-migration.md`: Full trilingual parity across English, Russian, and Ukrainian detailing the shadow-to-active migration lifecycle, source-pair upload, schema transformation, and cutover invariants.
  - `docs/rollback.md`: Full trilingual rollback and emergency recovery guide (EN/RU/UK) specifying Home Assistant snapshot restore, config entry removal, storage artifact cleanup, and state validation without data loss.

- **Strict Preconditions & Incident Lifecycle Carried Forward**:
  - MikroTik strict enforcement gate (`network/strict_preconditions.py`, 17 tests) with 9 explicit reason codes and owner evidence recording.
  - Network watch incident lifecycle (`network/watch.py`) with localized closure confirmation `network_watch_cleared` and quiet hours compliance.
  - 100% trilingual translation parity across all 975 translation keys in `strings.json`, `en.json`, `ru.json`, `uk.json`, and Telegram message templates.
