# 0.1.0 — Production Release (v1.0)

Family Assistant 0.1.0 is the first stable production release, delivering a local-first family workspace for Home Assistant.

## Core Capabilities

- **Local-First Architecture**:
  - Atomic persistence in Home Assistant storage (`.storage/family_assistant.*`).
  - Strict idempotency, operation replay protection, and atomic rollbacks on failure.
  - Zero external cloud dependencies, zero hidden developer telemetry.
  - Dedicated storage outside HACS-managed custom component directories.

- **Trilingual Parity (EN / RU / UK)**:
  - 100% parity across all 975 translation keys (`strings.json`, `en.json`, `ru.json`, `uk.json`).
  - 100% parity across all Telegram message templates in `telegram/messages.py`.
  - Comprehensive documentation in English, Russian, and Ukrainian (`docs/setup.*.md`, `docs/legacy-migration.md`, `docs/rollback.md`).

- **Own Telegram Bot**:
  - Self-hosted personal bot via Long Polling without third-party cloud bridges.
  - Owner-confirmed member enrollment (15-minute TTL tokens).
  - Strict role-based command dispatching (Owner, Parent, Child, Guest).
  - Natural language intent parsing with structured fallbacks and interactive inline buttons.

- **17 Lovelace Cards**:
  - Today, Tasks, Shopping, Alarms, Court, Routines, Calendar, Pantry, Meals, School, Maintenance, Polls, Presence, Digests, Network Admission, Network Watch, and Developer Diagnostics.
  - Dynamic responsive views for mobile and desktop, role-aware visibility.

- **Tasks & Household Organization**:
  - Full task lifecycle (checklists, due dates, independent multi-person assignments).
  - Photo and text completion reports with private parent review and rejection notes.
  - Atomic batch operations (bulk complete, cancel, archive) with optimistic concurrency control.
  - Recurring task schedules with timezone and DST safety.

- **Shopping & Inventory**:
  - GTIN barcode scanning, manual item creation, and category grouping.
  - Native Assist voice proposals and spoken confirmation in English, Russian, and Ukrainian.
  - Partial purchase tracking, price memory, and recurring staples preservation.
  - Meal planner integration with Mealie recipe importing.

- **Alarms & Challenges**:
  - Two-stage wake-up escalation with renewal sirens and quiet hours.
  - Mathematical nonce-challenges with SHA-256 hashed answer verification.
  - Configurable penalty rates with caps and automatic incident closure.

- **Court, Privileges & Routines**:
  - Reversible disciplinary point ledger with weekly snapshots and appeal processes.
  - Privilege catalog with reservations and parent approval.
  - Ordered routine runs with 3-valued conditional steps, mode awareness, and private confirmations.

- **Network Admission & MikroTik Kid Control**:
  - RouterOS REST API integration for DHCP lease management.
  - Safe static lease conversion wizard with preview and read-back validation.
  - Kid Control profiles with weekday/weekend/holiday schedules and bandwidth limits.
  - Unknown device discovery with quiet-hour batching and incident closure notifications (`network_watch_cleared`).
  - Strict admission gate enforcing hard topology preconditions (9 reason codes) before enforcement.

- **Safe Legacy Migration & Rollback**:
  - Non-destructive read-only copy wizard and sealed shadow mode isolation (`schema_version: "legacy-shadow-v1"`).
  - 7-module migration smoke suite (`tests/test_migration_critical_smoke.py`) ensuring zero mutation in shadow mode.
  - Trilingual migration contract (`docs/legacy-migration.md`) and rollback/recovery guide (`docs/rollback.md`).
