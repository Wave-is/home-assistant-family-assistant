## What's New

### Price Watch Module (`price_watch`)

A native price and availability monitoring module built directly into Family Assistant — no external scripts or separate containers needed.

#### Features

- **Add / Edit / Remove** tracked URLs via Telegram or the HA card
- **Price-drop notifications** — Telegram message when price falls below the previously recorded value
- **Back-in-stock notifications** — instant alert when `out_of_stock` → `in_stock`
- **30-snapshot history** per item — keeps the last 30 price readings
- **Up to 200 watchers** per household
- **Duplicate URL guard** — same URL cannot be added twice
- **SSRF protection** — private/loopback IPs are blocked before any HTTP request
- **Cloudflare detection** — `cf_blocked` error returned gracefully instead of crashing
- **Tracking-param URL cleaner** — strips `utm_*`, `fbclid`, `_gl`, etc. before storing
- **JSON-LD parser** — extracts `Product` / `ProductGroup` / `@graph` structured data
- **Fallback regex** — extracts availability from `itemprop` and inline JSON when JSON-LD is absent
- **30-minute polling** via `PriceWatchScheduler` (HA `async_track_time_interval`)

#### Permissions

| Role | Add | Edit | Remove | View |
|------|-----|------|--------|------|
| owner / parent | ✓ | ✓ | ✓ | ✓ |
| adult / child / guest | — | — | — | read-only |

#### Notifications (EN / RU / UK)

- `price_watch_drop` — "📉 Price drop: {name} — {old_price} → {new_price} {currency}."
- `price_watch_available` — "✅ Back in stock: {name} — {price_text}."
