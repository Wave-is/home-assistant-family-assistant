# 0.2.0-rc.3 — early command-learning release

**Pre-release / Ранняя версия / Рання версія.** Not full legacy parity, physical
device acceptance, or approval for unattended household migration.

- Unknown task recipients now reach inference; explicit assignment verbs,
  spacing, case and separators have RU/UK/EN regression coverage.
- A unique one-edit task-recipient correction can be independently proven against
  the strict parser and entire typed action. Only that narrow parent/owner task
  creation executes immediately; other model writes retain review.
- Task, private spelling rule and receipt commit atomically. Restart, duplicate
  delivery, failed Store writes, disabled rules and changing identities are tested.
  Future rule use is rechecked inside the transaction, not only during parsing.
- The conversation card distinguishes name spellings, inactive bindings and
  ordinary phrases, with rule disabling in all three languages.
- A configured AGY-compatible HTTP slot precedes the reviewed HA agent and direct
  Ollama primary/fallback. This is not a native AGY console bridge. See the exact
  [limitations and next priorities](../command-learning.md).
- Model-created tasks pin the visible recipient revision, including reviewed
  proposals, to prevent silent rebinding during inference or confirmation.

## Verification

Publish only after the exact commit passes Python, frontend, Chromium, privacy,
locale, packaging and isolated Home Assistant 2026.8.2 gates. New fixtures use
fictional members and synthetic providers with real Engine/router/Store contracts.
They do not establish live model accuracy or physical effects. The published
commit's Checks run provides final results.

## Installation and rollback

Use [HACS early access](../hacs-early-access.md) and explicitly select this
pre-release. A catalog submission is not catalog acceptance. Back up and verify
the previous runtime and HA data before changing an existing installation.
Config Entry Options and Store remain outside HACS-managed code.

Disable a spelling rule in the conversation card or with `/forgetphrase L...`;
correct/cancel an already created task separately. For code rollback, restore the
captured runtime or select the previous candidate through HACS, then use the
approved restart procedure. No Store edits, history deletion or automatic full
backup restoration is required. Publication does not change the live household.
