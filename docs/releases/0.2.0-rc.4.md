# 0.2.0-rc.4 — optional ordered text and image providers

**Pre-release / Ранняя версия / Рання версія.** Prepared candidate, not full
legacy parity or approval for unattended household migration. Publication and
deployment require their own reviewed, exact-commit acceptance.

## Changes

- Configure zero to eight ordered text providers in native **Configure → AI &
  Assistant → Language provider chain**. AGY's Ollama-compatible HTTP API,
  Ollama/Qwen servers and the separately reviewed HA agent are supported.
  Per-row enable, model, URL, key, timeout and order are explicit; AGY-first with
  two Qwen fallbacks is an optional arrangement, not a required installation.
- Existing AGY/HA-agent/primary/fallback settings remain the source until a new
  chain is saved. A saved empty chain is authoritative and never revives old
  providers. Provider fallback does not relax authorization, typed-plan review or
  the previously implemented narrow task-recipient learning proof.
- Configure images independently, for example **AGY Images API v1 → ComfyUI**.
  Native settings support metadata discovery without generation, offline drafts,
  explicit save/discard, and credential clearing in RU/UK/EN. ComfyUI supports
  bounded checkpoint and Z-Image Turbo presets, not arbitrary workflow imports.
- Authenticated members can explicitly request images in their private Telegram
  bot chat with `/draw` or supported drawing phrases; `/images` reports their own
  recent statuses. Generated output must be real, bounded, decoder-verified image
  bytes. Queuing, generating and Telegram delivery are distinct outcomes.
- The optional public [AGY CLI gateway](../../services/agy_gateway/README.md)
  provides authenticated metadata/chat, evidence-search and durable image-job
  APIs. It is separately installed and authenticated; HACS does not install it
  or require a developer PC. Deny-by-default hooks restrict completion, exact
  search and fresh image generation. CLI schema requests are independently
  validated without relying on the observed unreliable CLI schema flag.
- Adult AGY search is separately opt-in and accepts only completed search-tool
  evidence. Missing evidence can use configured SearXNG; fabricated links in
  prose cannot become sources. Child search stays on the existing guarded search
  path because AGY safe-search support is not established.
- Image readiness is optional and distinguishes configuration from initialized
  adapters. Neither means a live connection or successful generation. Runtime
  replacement clears stale errors; successful cleanup cannot hide unrelated
  generation or delivery errors.

Setup and exact contracts: [provider chains](../provider-chains.md),
[private image generation](../image-generation.md).

## Safety and limitations

All providers are optional. Ordinary deterministic commands work without them;
the integration does not power on an offline PC, install models or grant arbitrary
household tools to AGY. Only Ollama-compatible text endpoints are supported by
these HTTP adapters, not arbitrary OpenAI-compatible APIs. HTTPS is preferred;
plain HTTP requires an explicit endpoint-specific choice.

Only a definitive rejected/failed image attempt with no output permits fallback.
Timeout, interrupted execution, uncertain submission or uncertain Telegram
delivery does not silently start another image. Gateway IDs are bound to request
IDs, not prompt equality; changing a payload under the same ID is rejected.
ComfyUI does not provide equivalent submission idempotency, so a lost submission
acknowledgement is held for review. An HTTP poll failure is not proof that an
accepted image job failed.

Integration cache files and gateway workspaces have bounded 24-hour retention;
durable ID receipts remain to prevent replay after cleanup, with fail-closed
capacity limits. Remote ComfyUI outputs, Telegram messages and AGY's own private
history/source artifacts have separate retention. Local cleanup does not erase
them. Generated images are transient cache, not task-report evidence or part of
the household-report media backup registry. Actual AGY image dimensions may
differ from the requested size. See the linked contracts for exact bounds.

Live provider quality, GPU/model compatibility, Telegram delivery and a specific
household's network are separate acceptance gates. Legacy memory, voice and
other missing workflows remain visible in the
[legacy parity audit](../legacy-parity-audit.md); this increment does not close them.

## Installation and rollback

Use [HACS early access](../hacs-early-access.md) and explicitly select this
prerelease only after its exact checks pass. Capture and verify a backup and the
previous runtime before updating; preserve Config Entry Options and Store.
Upgrading code does not enable new providers or install the gateway/ComfyUI.

Disable the optional text/image chains before a code rollback, especially when
image generation or delivery is uncertain. Capture the current settings and job
status; do not delete receipt history to force a retry. Older code may ignore the
new provider list and read preserved legacy settings, so review those settings
before enabling inference again. Restore the reviewed previous runtime or HACS
version through the approved restart procedure. Gateway rollback is a separate
service operation with its own durable job storage; corrupt/unknown job metadata
must not be discarded to make a request run again. No direct Store edits or full
backup restoration are part of an ordinary code rollback.
