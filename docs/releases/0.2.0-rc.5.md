# 0.2.0-rc.5 — independent providers and grounded search

**Pre-release / Ранняя версия / Рання версія.**

This follow-up to [rc.4](0.2.0-rc.4.md) removes remaining legacy-primary
assumptions from conversation and article readiness. An explicitly configured
AGY-only or reviewed HA-agent-only chain no longer needs an unrelated legacy
Ollama slot. Disabled providers, an explicit empty list and stale runtime
configuration remain unavailable. Native HA-agent editing keeps its ordered row
consistent with the separately reviewed binding, without replacing other rows.

Search planning now permits bounded case, punctuation and source-word order
changes. Every query word must still originate in the **current** user request;
family names, private identifiers and addresses remain excluded. Models are
explicitly instructed not to translate or invent search concepts. One bounded
correction can use the current request only—not family state, quotes, history or
the rejected query—and must pass the same independent validation before any
external search. Unproven output still fails closed, and revocation stops the
whole operation. Search is terminal/read-only and cannot execute household tasks.

No provider URL, account, model selection or household setting is changed by
installing this code. The optional gateway and ComfyUI transport from rc.4 are
unchanged. Preserve Config Entry Options, Store and image receipts when updating;
take a backup and restart through your normal approved procedure. Do not edit
Store or delete receipts to force retries.

Publication requires the exact commit's complete Checks workflow, including
both supported HA versions. Release-page verification records the completed run.
This increment does not close the separate legacy-parity audit or imply default
HACS catalog acceptance.
