# 0.2.0-rc.6 — schools, natural commands and reviewer reminders

**Pre-release / Ранняя версия / Рання версія.**

- The optional per-child online-school connector is integrated with current
  text/image/search providers. Native setup, private schedules/homework/grades,
  freshness, read-only polling and opt-in paced notifications are documented in
  [the school guide](../online-schools.md). Each family supplies its own account;
  credentials remain in private HA Options, never in the public component.
- RU/UK/EN task commands separate terminal report requirements and deadlines
  from titles. Natural shopping quantities and named task-list queries use
  typed domain checks, role filtering and exact replay. Contradictions do not
  silently create a differently interpreted task. See [command coverage](../telegram-command-parity.md).
- Parents may optionally set a separate reviewer reminder interval in Tasks
  create/edit controls. One private reminder belongs to an exact submitted
  report generation; restart/retry cannot duplicate it and completion revokes
  pending delivery. Children are not penalized while waiting for adult review.
  Old tasks remain off. See [reviewer windows](../task-review-deadlines.md).
- New picker cards use namespaced `family-assistant-…-card` types, so preloaded
  legacy task/alarm cards cannot replace them. Existing resources are not removed.

## Обновление / Оновлення / Upgrade

Back up Home Assistant first, select this early release in HACS, restart Core
through the normal supported procedure, then refresh the browser. Config Entry
Options, family Store, learned phrases, tasks and image receipts are outside
the component and are not replaced by the runtime archive. School connection
and notification setup is explicit, not automatically enabled by an update.

Сохраните резервную копию, обновите ранний релиз через HACS, перезапустите НА
и обновите страницу. Школа подключается отдельно; новые напоминания о проверке
не включаются для старых задач. Никакие реальные устройства не активируются
самой установкой кода.

Збережіть резервну копію, оновіть ранній реліз через HACS, перезапустіть НА
та оновіть сторінку. Шкільні облікові записи налаштовуються окремо; старі задачі
не отримують нових нагадувань автоматично. Оновлення не активує фізичні пристрої.

## Limits and rollback

Use the documented [rollback procedure](../rollback.md), preserving Store and
Options. Rolling code back to rc.5 removes school functionality; it is not a
school-data restore. Disabling/rebinding a school source currently invalidates
its cache generation, so capture the source configuration before changing it.
Do not edit `.storage`, erase receipts or resend an uncertain school save.

Assigned shopping, atomic multi-task prose, daily task rollover/corrections,
scoped conversational memory, Telegram STT and the remaining household/energy
mappings are still open in [legacy parity](../legacy-parity-audit.md). Real
nonempty school grade/file acceptance and physical siren/router tests are not
implied by synthetic suites. Default HACS catalog inclusion is independent.

Local combined acceptance: 6245 Python tests (six platform skips, 23 subtests),
426 actual Chromium scenarios, native HA2026.9.2 school/command-completion checks,
and a two-process exact rc.5-to-rc.6 upgrade passed. The frontend inventory records
observed synthetic actions and unvisited paths separately; this is not physical
device acceptance or proof of every possible natural-language request.

The release page must link the exact commit's complete Checks results, including
both supported HA versions. No whole-vision completion is claimed by this increment.
