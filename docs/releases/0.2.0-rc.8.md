# 0.2.0-rc.8 — on-demand home readings and precise task settlements

**Pre-release / Ранняя версия / Рання версія.**

- Optional [home status](../home-status.md): reviewed registered sources, named
  groups, explicit active-state mappings and five energy readings. Manual card,
  API and private Telegram requests enforce current family roles and HA source
  permissions. Unknown, stale and unavailable readings are labelled; no physical
  activity is inferred. Idle card checks only revoke stale access, not poll devices.
- Optional [task settlements](../task-settlements.md): parent-reviewed daily
  rollover, separate repeat-penalty consent and exact same-day completion
  correction. Old days after downtime are skipped without a penalty avalanche.
  Immutable dated receipts survive reload/replay; full history is retained up to
  366 receipts, when only that policy pauses for review. The card shows the last
  settlement; a full historical receipt browser is not yet included.
- Dashboard chat and native Assist deterministic commands no longer occupy the
  same admission lane as slow model work. Optional provider work retains bounded
  global/per-member concurrency, authority checks and replay protection.
- School periodic synchronization now runs on HA's event loop. The previous
  synchronous timer listener could complete the initial fetch but fail on later
  ticks, preventing scheduled notices. A real HA timer/HassJob regression now
  covers repeated dispatch, duplicate start and a queued callback after stop.

## Обновление / Оновлення / Upgrade

Back up HA, install this prerelease through HACS, perform the supported Core
restart and refresh the browser. Config Entry Options and family Store remain
outside component files. New home mappings and task policies start disabled;
installation does not enable alarms, penalties, network rules or device commands.

Сводка дома включается отдельно с выбором разрешённых сущностей. Перенос задачи,
повторный штраф и точная отмена штрафа — три отдельные настройки родителя.
Данные дома доступны только по запросу; сводка не управляет устройствами.

Зведення дому вмикається окремо з вибором дозволених сутностей. Перенесення
завдання, повторний штраф і точне скасування штрафу — три окремі налаштування
батьків. Дані дому доступні лише за запитом; зведення не керує пристроями.

## Rollback and remaining scope

Follow [rollback](../rollback.md), retaining Store, Options and exact receipts.
Returning to rc.7 removes these new consumers; it is not a restoration of old
family data. Do not edit storage files or replay uncertain operations.

This is an increment, not completion of the [vision](../vision.md). Generic home
control, kettle operation, forecast comparison, scoped conversational memory,
Telegram media understanding and other [legacy gaps](../legacy-parity-audit.md)
remain separate work. Household siren/router acceptance, real nonempty school
grades/files and HACS default-catalog admission are separate gates.
