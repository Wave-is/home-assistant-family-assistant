# Настройка семьи

[English](setup.en.md) · [Українська](setup.uk.md)

Инструкция для разработки. **Рабочего публичного релиза пока нет.** Проверяйте
модуль в отдельном HA, не заменяя действующую семейную систему. Реальное
состояние функций указано в [матрице готовности](implementation-status.md).

## Установка и участники

Путь установки релиза: HACS → Пользовательские репозитории →
`Wave-is/home-assistant-family-assistant`, категория «Интеграция». Выберите
проверенный релиз, установите и перезапустите HA по запросу. Затем Настройки →
Устройства и службы → Добавить интеграцию → Family Assistant. Включение в
основной каталог HACS требует отдельного рассмотрения; пока оно не заявлено.

Одно подключение интеграции — одна семья. Создаёт её администратор HA: название,
своё имя, язык, часовой пояс IANA, например `Europe/Kyiv`, и шаблон. Остальные
участники шаблона — редактируемые заготовки без аккаунтов и доступа.

В «Настроить → Участники» владелец меняет имена, роли, языки и привязывает
пользователей HA. В поле других имён укажите формы имени по одной на строку:
например, именительный и дательный падежи. Одинаковые имена требуют уточнения.
Родители подтверждают задачи; роль «Взрослый» сама по себе не даёт родительских
прав. Ребёнок видит только свои задачи, будильники и баллы.

Данные и секреты хранятся в конфигурации HA и Store вне `custom_components`.
Обновление кода не заменяет их. Резервные копии HA держите приватными. Не
публикуйте `.storage`, токены и логи без проверки и не редактируйте Store вручную.

## Каждый создаёт своего бота

1. Откройте проверенного `@BotFather`, отправьте `/newbot`, задайте имя и
   уникальное имя пользователя с окончанием `bot`. Никому не передавайте токен.
2. Family Assistant → Настроить → Подключить своего Telegram-бота: включите
   подключение и вставьте токен в защищённое поле. При последующем редактировании
   пустое поле сохраняет старый токен. Выключение не удаляет данные семьи.
3. Добавьте бота в домашнюю группу. В HA выберите привязку семейной группы,
   отправьте туда показанную команду `/family_setup@ваш_бот КОД`.
4. Продолжите форму ожидания, проверьте найденные название и ID, подтвердите в
   HA. Само получение кода ещё не даёт доступа.
5. Для каждого человека откройте привязку личного чата. Именно этот человек
   должен открыть выданную ссылку и нажать «Старт». Проверьте найденный аккаунт
   и подтвердите в HA. Личные чаты родителей нужны и для приватных уведомлений.
6. Напишите в группе `@ваш_бот тут?` или `/ping@ваш_бот`, подставив настоящее
   имя бота. Эта проверка работает без LLM.

Сторонний бот для определения ID не нужен. Telegram не разрешает боту первым
начать личный разговор. Код действует 15 минут; просроченный замените новым.
Не публикуйте ссылки приглашения.

Для команд, упоминаний и ответов оставьте Privacy Mode включённым. Обращаться
можно ответом на сообщение бота. `/setprivacy` в BotFather управляет доставкой
сообщений группы; после отключения приватности может понадобиться повторно
добавить бота. **Получение всех сообщений не включает ответы на весь разговор:**
текущая версия всё равно ждёт прямого обращения.

У одного токена должен быть только один обработчик. Нельзя одновременно
использовать его здесь, в стандартной интеграции Telegram Bot и другой
программе. При конфликте webhook/poller сначала остановите прежний обработчик.
Family Assistant не удаляет webhook чужого приложения.

## Команды без LLM

| Команда | Действие |
| --- | --- |
| `/help`, `/ping` | Справка и быстрая проверка |
| `/shopping` | Отдельный список покупок |
| `/buy Молоко \| 2 \| л` | Добавить товар; заявку ребёнка одобряет родитель |
| `/bought S000001` | Куплен весь оставшийся объём |
| `/tasks` | Доступные задачи |
| `/task Ребёнок 1 \| Собрать рюкзак` | Назначить задачу по имени или псевдониму |
| `/done T000001 \| Всё собрано` | Сдать текстовый отчёт |
| `/approve T000001` | Родитель подтверждает выполнение |
| `/stats` | Баллы и конкретные причины |
| `/alarms` | Расписания подъёма |

Поддерживаются отдельные обычные формулировки: «Ребёнок 1 задача собрать рюкзак,
срок до конца недели». Ответ на подтверждение этой задачи: «установи срок
завтра». Конец недели — воскресенье, время по умолчанию — 20:00 в часовом поясе
семьи. Прошедший срок, неверная дата и неоднозначное время перевода часов не
подставляются молча. Цитата должна ссылаться на реально отправленное ботом
сообщение с сохранённым подтверждением отправки. Копия текста этого не заменяет.

Это ограниченная грамматика, а не обещание понять любую фразу. Непонятный
запрос не меняет данные. Подключение LLM и поиска пока в разработке; скрытого
облачного провайдера разработчика нет.

## Карточки

Пока ресурс не регистрируется автоматически: включите расширенный режим
профиля HA, откройте ресурсы дашбордов и добавьте JavaScript-модуль
`/family_assistant/frontend/family-assistant.js`. Обновите страницу и добавьте
карточку Family Assistant из списка. Визуальный редактор предлагает семьи,
связанные с вашим аккаунтом, — вручную копировать ID не нужно.

Разделы: сегодня, покупки, задачи, будильники, правила/поощрения и состояние
системы. Карточка использует язык интерфейса HA, бот — язык участника. Сервер
проверяет права независимо от видимости кнопок.

## Будильник и доставка

Заведите отдельные расписания будней и выходных. Мягкий режим — только
сообщения. Строгий добавляет **отдельную** сирену, назначенную с подтверждением
в настройках интеграции. Не используйте пожарную или охранную сигнализацию.
Громкость проверьте физически: состояние HA не доказывает наличие звука.
Перед тестом карточка спрашивает ещё раз; тест не штрафует.

Первая свежая мини-капча останавливает звук. Через случайные 12–18 минут по
умолчанию приходит вторая; без ответа после разрешённой паузы строгий режим
снова включает звук. Старая кнопка или ответ другого человека не засчитываются.
Автоштрафы изначально выключены и ограничиваются отдельным дневным пределом.

На карточке состояния видны ошибки доставки. Тайм-аут может возникнуть после
принятия сообщения Telegram, поэтому автоматического слепого повтора нет.
Посмотрите чат и либо закройте предупреждение, либо явно подтвердите повтор с
причиной и согласием на возможный дубль. «Ожидается чат» — привяжите получателя.

Перед рабочим использованием проверьте права всех участников, упоминания,
цитаты, повтор команды, сохранение данных после перезапуска и оба этапа
будильника, пока все бодрствуют. До проверки держите автоштрафы выключенными.
Публичный релиз, миграция и проверка устройств — отдельные этапы приёмки.
