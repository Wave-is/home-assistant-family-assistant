# One chore, separate assignments / Отдельные задачи / Окремі завдання

## English

In the Tasks card, select Add, then **Assign to multiple people**. Select 1–20
active people; no one is preselected. Enter the chore, deadline, steps, required
report and optional reminder/penalty policy. Review the complete names and
settings, confirm, then create the tasks.

Each person receives a separate task with its own ID, checklist, report and
completion. This is not one jointly completed task. Completing one person's task
does not complete another's; automatic penalties remain opt-in and independently
capped. One atomic command creates the whole group. A stale reviewed member or
invalid target causes no partial creation.

Deadlines use the household time zone. Repeated daylight-saving times require
an explicit occurrence. Back preserves the wall time and occurrence. If the reply
is lost, Retry retains the original command and ID even after another card
command; closing does not undo already-created tasks. Changed users, roles or
member bindings revoke stale drafts. A private personal reminder remains self-only.

## Русский

В карточке задач нажмите «Добавить» → «Назначить нескольким людям». Выберите
1–20 активных участников: заранее никто не выбран. Укажите дело, срок, шаги,
требуемый отчёт и при необходимости правила напоминаний/штрафов. Проверьте
полный список имён и настройки, подтвердите и создайте задачи.

Каждому создаётся отдельная задача со своим номером, шагами, отчётом и отметкой
выполнения. Выполнение одного участника не закрывает задачи остальных.
Автоштрафы включаются отдельно; ограничения действуют для каждого. Весь набор
создаётся одной транзакцией: устаревшая привязка или неподходящий участник не
оставляет частично созданных задач.

Срок задаётся в часовом поясе семьи. При повторяющемся времени перехода часов
нужно выбрать вхождение. «Назад» сохраняет время и выбор. Если ответ потерян,
повтор отправляет ту же команду с тем же ID даже после другой команды карточки.
Закрытие не отменяет уже созданные задачи. Смена пользователя, прав или привязок
сбрасывает старые формы. Личное напоминание по-прежнему можно создать только себе.

## Українська

У картці завдань натисніть «Додати» → «Призначити кільком людям». Оберіть
1–20 активних учасників: заздалегідь нікого не вибрано. Вкажіть справу, термін,
кроки, потрібний звіт і за потреби правила нагадувань/штрафів. Перевірте всі
імена та налаштування, підтвердьте й створіть завдання.

Кожному створюється окреме завдання зі своїм номером, кроками, звітом і статусом.
Виконання одним учасником не закриває завдання інших. Автоштрафи вмикаються
окремо й мають індивідуальні обмеження. Увесь набір створюється однією
транзакцією: застаріла прив’язка або недопустимий учасник не залишає частини завдань.

Термін використовує часовий пояс родини. Для повторюваного часу переведення
годинника потрібно обрати входження. «Назад» зберігає час і цей вибір. За втрати
відповіді повтор надсилає ту саму команду з тим самим ID навіть після іншої
команди картки. Закриття не скасовує вже створених завдань. Зміна користувача,
прав чи прив’язок скидає старі форми. Особисте нагадування залишається лише для себе.
